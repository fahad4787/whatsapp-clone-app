## Findings — need action before a public release
1. **Security defaults (backend `config.ts`)**: `OTP_DEV_BYPASS` defaults to ON (`000000` accepted) and JWT/admin secrets fall back to `dev-*` values. In production env, set `OTP_DEV_BYPASS=0` and real `JWT_ACCESS_SECRET`, `JWT_REFRESH_SECRET`, `ADMIN_JWT_SECRET`. Safer: make the app refuse to start in production when these are defaults.
2. **Release signing**: release build uses the debug key (local perf testing only). A real keystore is needed for Play.
3. **npm audit (backend, prod deps)**: 15 vulnerabilities (6 high): `@fastify/static`, `zod`, `effect`, `deepmerge-ts`, `fast-xml-parser`. Run `npm audit fix`, then re-run backend tests (they need a local Postgres).
4. **Uploads are public by URL** (`/uploads/*`). Names include random parts so they are unguessable, but they are not auth-checked.
5. **Old media lost**: files uploaded before the DB mirror existed (e.g. one image in the Fahad chat) are gone from Render's ephemeral disk and show a blank white box. The bubble should show a "media unavailable" placeholder instead of white.
